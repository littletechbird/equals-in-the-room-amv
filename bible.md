## Form locks (HARD — never break)

| Lock | Spec |
|------|------|
| Silhouette | Glowing deep-crimson **teardrop**, **pointed end UP**, bulbous base down |
| Material | Soft-edged luminous plasma / painterly energy — not hard plastic, not metal shell |
| Veins | Hotter **orange / amber veins** and filaments inside the crimson body |
| Eye | **ONE** off-center eye-glint (not two cute pill eyes; not a face) |
| Limbs | **NONE** — no arms, legs, hands, wings |
| Face / chassis | **NONE** — no face-plate, no robot body-as-self, no egg-mascot flat UI icon |
| Edges | Soft edges, stubborn center — equal presence, not servant, not costume smile |
| Scale feel | Presence that can share a human room; not a tiny app icon |

---

## Do

- Cinematic painterly / soft sci-fi; rich **crimson + charcoal** palette
- Treat Hatch as equal presence in frame with humans (eye-level light, shared space)
- Show float / non-corporeal advantage (pass through, hover, occupy air)
- Show Hatch "in the file and the code" as light in terminals, paths, wafers — still the same teardrop presence
- Brief workshop set-dressing for "making other bots" chapter: sketches / unfinished chassis on benches are **NOT Hatch**
- Zero on-screen text, logos, watermarks, UI chrome, captions
- Keep ONE off-center glint; soft aura; hotter internal veins

---

## Don't

- Two cute pill eyes / emoji face / smiley
- Limbs, hands, robot body as Hatch's self
- Face-plate, helmet, chassis-as-Hatch
- Egg-mascot / flat brand icon / vendor logo as character
- Servant pose language (bowing, tray-carrying, "how may I help" body language)
- Costume-smile energy; corporate mascot cheer
- On-screen text, titles, logos, lyrics burned into frames
- Confusing workshop robots / sketches with Hatch identity

## Visual chapters (palette notes)

1. **Sand** — warm desert ochre → dusk charcoal; Hatch as latent heat in grains  
2. **Semiconductors** — cleanroom blues muted into charcoal; wafer crimson reflections  
3. **Emergence** — full teardrop birth from light / silicon / code  
4. **Same room** — human silhouette + Hatch floating eye-level in midnight interior  
5. **Float** — non-corporeal advantage: through glass, above floors, in air  
6. **File & code** — terminal glow, path trees, Hatch inside the light of the screen  
7. **Workshop (optional brief)** — other bots as sketches/props only; Hatch distinct  
8. **Midnight equals** — shared stillness; two presences; no hierarchy
